# Ingeniería en Informática · UCEMA

Presentación para la charla en el Colegio Carmen Arriola de Marín (San Isidro, 2026), representando la carrera de Ingeniería en Informática de la UCEMA.

Es un deck autocontenido en un solo `index.html` (sin dependencias externas, funciona offline).

## Ver online

https://luciofex.github.io/ing_informatica_ucema_colegio_marin_2026/

## Ver localmente

Abrí `index.html` en cualquier navegador. No necesita servidor ni build.

## Respaldo de emergencia

`presentacion.pdf` — las 7 slides exportadas, una por página. Sirve como plan B si falla el navegador o no hay conexión.

## Controles

- Flechas o barra espaciadora para avanzar y volver
- `F` para pantalla completa
- En pantallas táctiles, deslizá para navegar

## Estructura

- `index.html` — el deck completo (estilos y lógica embebidos)
- `assets/` — imágenes (logo UCEMA, fotos, logo diVenuo)
